Format

vCard carries every field and works on iPhone and Android. MeCard makes a smaller, easier-to-scan code but leaves out the job title.

Style

Keep the code dark on a light background. Gradients scan best when both colors are dark.

Logo

A logo hides part of the code, so adding one switches error correction to H. Use a PNG or SVG with a transparent background so the code can wrap around the logo's shape. Keep it at 25% or less and test-scan before printing. The image never leaves your browser.

This browser

Saves every field, style choice and logo on this device only, so they are filled in next time you open the page. Nothing is sent anywhere. Untick to delete the saved copy.

To save the PNG, right-click the code (or long-press on a phone) and choose Save image.
