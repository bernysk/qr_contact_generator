Color presets

Every combination is dark enough on its background to scan reliably.

Keep the code dark on a light background. Gradients scan best when both colors are dark.

Logo

A logo hides part of the code, so adding one switches error correction to H. Use a PNG or SVG with a transparent background so the code can wrap around the logo's shape. Keep the “Logo covers” chip green and test-scan before printing. The image never leaves your browser.

Several contacts

Make codes for a whole team: fill in the CSV template in Excel or Google Sheets, import it, and download every code at once in the current style.

    Downloading every code as a ZIP works on the GitHub version of this page.
